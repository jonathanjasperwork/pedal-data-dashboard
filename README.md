# Padel Court Analytics

A Streamlit dashboard for analyzing padel courts in Indonesia using a dataset of approximately 1,400 courts.

## Features

- Market Analysis: Court distribution, ratings, tiers, and pricing.
- Court Recommendations: Compare courts by price, rating, tier, and location.
- Playing-Time Analysis: Analyze listed prices by day and hour.
- Geographic Analysis: Explore court distribution and pricing by province and city.

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

## Dataset

The dataset contains padel court information, ratings, locations, tiers, publication statuses, and listed schedule prices. The JSON dataset is stored in a ZIP archive.

## Deployment

The application is deployed using Streamlit Community Cloud.

## Limitations

Analysis uses a single data snapshot.
Listed schedules do not represent confirmed bookings.
Future price changes are not predicted.
